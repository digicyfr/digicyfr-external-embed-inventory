# Digicyfr External Embed Inventory 0.1.0 — website draft

## English

**Find external hosts referenced in saved content.** This free, open-source WordPress plugin scans published posts and pages locally and groups supported saved embed and resource references by host and source page. It labels `core/embed` provider URLs and lazy attributes as hints, so editors can review the saved source without mistaking a reference for a browser request. Scans are bounded and resumable, with a private administrator report, source coverage, stale indicators and CSV. It does not change content, fetch URLs, block resources, add front-end output, or decide privacy compliance.

WordPress 7.1+, PHP 8.3+, and InnoDB required. Local test evidence and exact ZIP checksum are in the source QA record; compatibility beyond tested versions is not claimed. GPL-2.0-or-later. Upload the ZIP under Plugins → Add New → Upload Plugin. Updates are manual.

## Polski

**Znajdź zewnętrzne hosty wskazane w zapisanej treści.** Ta bezpłatna wtyczka WordPress open source lokalnie skanuje opublikowane wpisy i strony oraz grupuje obsługiwane odwołania do osadzonych zasobów według hosta i strony źródłowej. Adresy dostawców z bloków `core/embed` i atrybuty leniwego ładowania są oznaczone jako wskazówki, aby redaktor nie mylił zapisanego odwołania z faktycznym żądaniem przeglądarki. Skan jest ograniczony i można go wznowić; prywatny raport administratora zawiera źródła, zakres, oznaczenia nieaktualnych stron i CSV. Wtyczka nie zmienia treści, nie pobiera adresów, nie blokuje zasobów, nie dodaje treści na stronie publicznej i nie ocenia zgodności z przepisami.

Wymaga WordPress 7.1+, PHP 8.3+ i InnoDB. Dowody lokalnych testów i sumę kontrolną ZIP zawiera dokument QA w źródłach; zgodność z innymi wersjami nie jest potwierdzona. Licencja GPL-2.0-or-later. Prześlij ZIP przez Wtyczki → Dodaj nową → Wyślij wtyczkę. Aktualizacje wykonuje się ręcznie.
